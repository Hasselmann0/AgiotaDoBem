# AgiotaDoBem  

Um software criado para aquelas pessoas que gostam de emprestar dinheiro para familiares ou amigos.  
Como agiotagem é crime, aqui não há cobrança de juros — o foco é apenas na **organização**.  
O sistema ajuda a manter os dados dos devedores de forma clara, simples e organizada em tabelas.  

## 🎯 Objetivo  
Organizar as despesas e empréstimos de forma clara e objetiva.  

## 🚧 Status do Projeto  
Em desenvolvimento.  

## 🛠 Tecnologias Utilizadas  
- C#  
- SQL Server  
- TypeScript  
- Angular  
- HTML  
- CSS  

## 🔮 Futuras Melhorias  
- Sistema de login:  
  - O credor poderá visualizar todos os registros.  
  - O devedor poderá acessar apenas as suas dívidas.  
- Gerenciamento de dívidas de cartão de crédito. 
  - semelhante às tabelas de gastos feitas no Excel.
